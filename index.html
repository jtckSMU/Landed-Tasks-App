To add someone, in Supabase open Authentication → Users → Add user → Create new user:
  1. Email: their username followed by (for example )
  2. Password: a starting password you give them
  3. Tick Auto Confirm User, then Create user.
  4. They appear here switched off. Tick Can log in and press Save.
